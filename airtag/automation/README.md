**AirTag Automation Run Instructions**

1. Download the directory 'airtag' and move into the working directory 'automation' using these commands.

```
cd airtag 
cd automation
pwd                     # should yield $/airtag/automation
```

2. The main script is **test_env_a.sh**, simply run this using the command:
```
bash test_env_a.sh
```
